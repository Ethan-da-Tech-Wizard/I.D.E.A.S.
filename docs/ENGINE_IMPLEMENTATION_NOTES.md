# Engine Implementation Notes

These notes translate the start-to-end goal into concrete implementation work.
They are intentionally incremental so the codebase keeps passing tests and the
security audit after every slice.

## Slice 1: Make the Existing Engine Usable

### Viewport

- Add a selected node id to `ViewportWidget`.
- Hit-test top-level nodes from front to back.
- Select objects with left click.
- Drag selected objects by left mouse movement.
- Keep existing middle-mouse/Ctrl-drag panning.
- Add optional grid drawing behind scene objects.
- Add grid size and snap-to-grid controls.
- Add reset camera and zoom-to-fit helpers.
- Serialize selected node, grid settings, and camera settings.

### Workspace

- Replace the bare two-tab wrapper with a usable Engine workbench.
- Add toolbar buttons for rectangle, circle, line, polygon, select, play,
  pause, reset, grid, snap, reset camera, and zoom fit.
- Add physics controls for gravity, floor, bounds width, and simulation step.
- Keep the shader builder as a first-class tab inside the Engine workbench.
- Keep dock panels attached by `PanelManager`; deeper panel content can follow
  after the viewport and data model are stable.

### Physics

- Use the existing ECS and physics system as the simulation data model.
- Mirror scene nodes into ECS entities for simulation.
- Preserve an edit baseline so Reset returns to the pre-play state.
- Do not make physics playback run when the Engine widget is not active.

### Shader Builder

- Add deterministic shader descriptor generation from graph JSON.
- Output should be text and JSON-compatible.
- Do not compile or execute shader code.

### Themes

- Add `import_theme(source_path, theme_name)` to copy a validated `.qss` into
  the configured theme directory.
- Add `export_theme(theme_name, destination_path)` to copy a validated theme out
  to a user-selected `.qss` file.
- Keep the existing default, dark, and light themes intact.

### Dock Layouts

- Add layout persistence helpers that are keyed per mode name.
- Validate mode names like theme names.
- Store opaque Qt layout bytes as base64 in JSON.

## Test Plan

- Viewport: selection, hit testing, move, grid/snap state, reset/fit camera.
- Workspace: object creation, physics play/pause/reset, state round-trip.
- Shader builder: descriptor generation includes nodes and connections.
- Theme engine: import/export copies only safe `.qss` files and rejects invalid
  suffixes/traversal names.
- Dock panels: per-mode layout save/restore and invalid mode rejection.
- Full suite and `scripts/security_audit.py` after implementation.

## Security Review Notes

- No new dependencies.
- No subprocess use.
- No sockets.
- No dynamic imports.
- No code execution.
- Theme import/export performs local file copy only after path/suffix/size
  validation.
- Shader descriptor generation returns inert text only.
- Dock layout persistence stores app-generated bytes only.

## Slice 2: Core Editor Loop

### Scene Model

- Extend `SceneNode` with editor-facing metadata and physics fields:
  `display_name`, velocity, mass, static/dynamic, collider size, trigger flag,
  restitution, friction, damping, gravity scale, and collision layer.
- Keep all values JSON-compatible.
- Parent/child hierarchy remains represented by nested `SceneNode.children`.
- Moving a parent applies the same delta to descendants for this pass.

### Inspector

- Add an Engine inspector area with fields for the selected object.
- Update the selected `SceneNode` through one workspace method so tests can
  cover inspector behavior without pixel rendering.
- Rebuild physics ECS after inspector edits that affect physics data.

### History

- Add a bounded undo/redo state stack for Engine workspace state.
- Record state before creation, deletion, duplication, movement, and inspector
  edits.
- Undo/redo restores viewport and shader/physics state from existing
  serialization methods.

### Scene Import/Export

- Add `scene_io.py` under `app/ui/engine/`.
- Export standalone `.ideas-scene` JSON through explicit user-selected paths.
- Import `.ideas-scene` JSON with UTF-8, regular-file, suffix, size, and schema
  checks.
- Imported scenes load through `EngineWorkspace.load_state()`.

### Shortcuts

- Add shortcuts for Delete, Ctrl+D, Ctrl+Z, Ctrl+Y, Space, F, G, and S.
- `S` toggles snap rather than saving; workspace file save remains under the
  existing File menu unless a user-selected scene path is provided.

### Tests

- Scene node metadata round-trip.
- Parent movement moves children.
- Inspector edit updates selected node and physics world.
- Undo/redo around create/delete/duplicate/edit.
- Scene import/export rejects bad suffixes and round-trips valid files.

## Slice 3: Schema Hardening

### Limits

- Cap total scene nodes, hierarchy depth, polygon points, node id length,
  display name length, coordinates, node size, velocities, mass, restitution,
  friction, damping, gravity scale, and collision layer.
- Validate duplicate ids across the entire scene graph, including children.
- Validate standalone scene imports by loading the scene graph through the same
  schema path used by the viewport.
- Bound undo/redo by serialized byte size as well as entry count.

### Negative Tests

- Reject duplicate child ids.
- Reject excessive hierarchy depth.
- Reject excessive polygon points.
- Reject out-of-range numeric values.
- Reject oversized undo history payloads.
- Reject malformed `.ideas-scene` graph data.

## Slice 4: Live Engine Dock Panels

### Scene Tree Panel

- Add `EngineSceneTreePanel` under `app/ui/engine/panels.py`.
- Populate from `EngineWorkspace.viewport.scene_graph`.
- Store node ids on tree items with `Qt.UserRole`.
- Selecting a tree item calls `viewport.select_node()`.
- Viewport selection changes refresh tree selection.
- Provide an explicit `refresh()` method for tests and future hooks.

### Properties Panel

- Add `EnginePropertiesPanel` under `app/ui/engine/panels.py`.
- Bind to the selected node and expose the most important fields in dock form:
  name, id, shape, color, transform, size, physics body, collider, and material
  controls.
- Apply edits through `EngineWorkspace.update_selected_node()` so validation,
  history, physics rebuild, and viewport update remain centralized.

### Integration

- In `MainWindow.build_engine_mode()`, register Engine-specific panel factories
  instead of the placeholder `register_example_panels()` factories.
- Keep Console as the existing inert console panel.
- Preserve the existing hide/show behavior when switching modes.

### Tests

- Scene Tree panel reflects live hierarchy.
- Tree selection selects viewport object.
- Viewport selection updates tree selection.
- Properties panel apply updates selected node through the workspace.
- Application builder exposes Engine panel registration without instantiating a
  full app in logic-only tests where possible.
